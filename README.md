# Spatial Orchestra Studio

브라우저에서 음악 파일을 분석하고 대편성 오케스트라 배치 기준으로 공간음향을 만드는 로컬 웹 앱입니다. 파일은 서버로 전송하지 않고, Web Audio API로 디코딩·분석·재생·WAV 렌더링을 처리합니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

## 포함된 기능

- 업로드 오디오 디코딩: MP3, WAV, M4A, AAC, OGG, FLAC 등 브라우저가 지원하는 형식
- 음악 분석: 파형, 라우드니스, RMS/Peak dBFS, 근사 LUFS, 크레스트, 다이내믹 레인지, 클리핑, DC 오프셋
- 리듬/화성 분석: BPM, 온셋 밀도, 조성 추정, 주요 피치, 크로마 기반 confidence
- 주파수 분석: 스펙트럼, 스펙트로그램, 중심 주파수, 롤오프, 스펙트럼 확산, 평탄도, 대역별 에너지
- 스테레오 분석: 좌우 상관도, Mid/Side 기반 폭
- 구조 분석: 8개 구간별 에너지, 밝기, 밀도, 구간 성격
- 자동 리마스터링: 분석 결과 기반 EQ, 라우드니스 보정, 글루 컴프레션, 소프트 리미터, 무대 폭 보정
- 공간음향 생성: 현악 전방, 목관 중앙, 금관 후방, 팀파니/타악 최후방 배치
- 저장: 공간 리마스터 결과를 16-bit PCM WAV로 렌더링해 저장

## 디자인

자연친화적인 밝은 스튜디오 톤을 라이트 모드로, 깊은 숲과 흙색 계열을 다크 모드로 구성했습니다. Greenery, Peach Fuzz, Living Coral, Cerulean, Mocha 계열의 팬톤풍 색을 참고해 두 모드 모두 숲, 흙, 햇빛, 하늘의 느낌이 유지되도록 조정했습니다. 상단의 `Dark`/`Light` 버튼으로 한 번에 전환할 수 있고 선택값은 브라우저에 저장됩니다.

## 공간화 방식

원본 음악에서 실제 악기 스템을 완벽하게 분리하는 방식은 아닙니다. 브라우저 단독 실행을 기준으로 주파수 대역과 어택 성분을 악기군처럼 나누고, 각 대역을 오케스트라 좌석 위치에 맞춰 HRTF Panner, 거리 지연, 홀 리버브, 자동 마스터 EQ, 글루 컴프레서, 리미터로 합성합니다.

## 파일

- `index.html`: 화면 구조
- `styles.css`: 반응형 UI와 오케스트라 무대 시각화
- `script.js`: 분석, 공간화 재생, WAV 렌더링
